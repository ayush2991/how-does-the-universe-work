An Intuitive Guide To Entropy

Understanding why entropy is a measure of chaos.

By Aayush Agarwal • Interactive Explorable • 8 min read
Prerequisite: An understanding of the Expected Value of discrete random variables.
If you know that the expected value is simply a probability-weighted average of all possible outcomes, you are ready to derive entropy from scratch.

1. Certainty and Zero Surprise

Imagine a coin-tossing scenario with the following outcomes and corresponding probabilities:

Outcome Probability
Heads (H) 1
Tails (T) 0

These values indicate that the coin always shows up Heads (H).

If we know in advance that the outcome will always be Heads, we experience zero surprise when we see the actual outcome. It is always H. There is no uncertainty and no information gained when the coin lands.

2. Generalizing Surprise

More generally, say p is the probability of outcome H.

If we use X to denote a random variable which records the outcome of a coin toss, then X takes values in {H, T}. Then:

Pr(X = H) = p      and      Pr(X = T) = 1 - p

X Pr(X)
H p
T 1 - p

How do we now generalize the "surprise"?

First, the surprise is now potentially non-zero, as the outcome is not pre-determined.

There could be any number of ways to quantify surprise, but we intuit some properties it must exhibit:

1. When an outcome is unlikely: the surprise upon its occurring should be high.
2. When an outcome is quite likely: the surprise must be low.
3. In the extreme case where p = 1.0: the outcome H is certain, and the surprise associated with it must be zero.

To satisfy these properties, we use log(1/p) to quantify the surprise associated with an outcome of probability p.

Surprise: S(p) = log( 1 / p ) = -log( p )
For guaranteed outcomes with p = 1.0, log(1/1) = 0. Outcomes with small values of p result in a large surprise.

Using base 2 logarithm gives units of bits.

3. Surprise of Repeated Tosses

Given this formulation, over the course of many coin tosses, we experience:

• A surprise S(H) = log(1/p) whenever the coin shows up Heads.
• A surprise S(T) = log(1/(1-p)) whenever it shows up Tails.

X Pr(X) S(X)
H p log(1/p)
T 1 - p log(1/(1-p))

Over repeated trials, what is the average surprise we experience?

4. Expected Surprise

To calculate the average surprise, we use the expected value of a discrete random variable:

E[Y] = ∑ y · Pr(Y = y)

Applying this to the surprise variable S(X):

E[ S(X) ] = p · log(1/p) + (1 - p) · log(1/(1 - p))
Using log(1/a) = -log(a), this is rewritten as:
Entropy = - [ p · log(p) + (1 - p) · log(1 - p) ]

This expected surprise is what is defined as entropy.

5. Why Entropy is a Measure of Chaos

Consider how this formula behaves across different values of p:

• When p = 1.0 (Guaranteed Heads): Entropy = -[ 1 · log(1) + 0 ] = 0.
• When p = 0.0 (Guaranteed Tails): Entropy = -[ 0 + 1 · log(1) ] = 0.
• When p = 0.5 (Fair Coin): Both outcomes are equally unpredictable. The formula gives:

Entropy = - [ 0.5 · log₂(0.5) + 0.5 · log₂(0.5) ] = 1.0 bit
At p = 0.5, entropy reaches its maximum value of 1.0 bit (or 0.693 nats with the natural logarithm).

Entropy is a measure of the inherent chaos of the system, rather than an observer's knowledge. When a system is predictable (p = 1 or p = 0), there is no uncertainty and entropy is zero. When outcomes are evenly balanced (p = 0.5), uncertainty is at its maximum.

6. Generalizing Beyond the Coin

This principle extends directly to any discrete random variable with n possible outcomes:

Entropy(X) = - ∑ᵢ₌₁ⁿ pᵢ · log(pᵢ)
Where pᵢ is the probability of the i-th outcome, and ∑ pᵢ = 1.

To connect this to everyday intuition, consider searching for an object in a house—such as a book or an omelette pan.

Suppose the object can be in one of four locations:

1. The Bookshelf  •  2. Under the Sofa  •  3. The Kitchen  •  4. The Bathroom

Consider three different scenarios:

• Scenario A (Chaotic Environment): If the object is equally likely to be in any of the four spots (p = 0.25 each), the environment is unpredictable. You have no indication where to begin searching. Because the probability is uniformly distributed, entropy is maximized:

H = - 4 · [ 0.25 · log₂(0.25) ] = log₂(4) = 2.0 bits
With 4 equally likely locations, entropy reaches its maximum of 2.0 bits (or 1.386 nats).

• Scenario B (Orderly Environment): If the object is on the bookshelf 94% of the time (p = 0.94), with only a 2% chance of being in any other room, the environment is orderly. You can reliably look on the shelf first. Entropy drops to approximately 0.44 bits (or 0.31 nats).

• Scenario C (Certain Location): If the object is always under the sofa with certainty (p = 1.0), the arrangement might be unconventional, but mathematically it contains no uncertainty. Since you know where it is in advance, surprise is zero, and entropy is strictly 0.

Summary

Reviewing the progression:

1. Certain outcomes deliver zero surprise. If an outcome is known in advance, observing it provides no new information.
2. Rarity dictates surprise. An outcome with probability p carries surprise S(p) = log(1/p).
3. Entropy is expected surprise. Across repeated trials, the average surprise experienced is -∑ pᵢ · log(pᵢ).
4. Entropy measures the inherent chaos of the system. Because the outcome of a non-deterministic process cannot be determined in advance, each event carries some surprise.

This randomness is an intrinsic property of the system itself and does not depend on the observer. When outcomes are equally likely, entropy reaches its maximum value. When the system is biased or deterministic, entropy decreases toward zero.
